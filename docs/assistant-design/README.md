# 项目协作助手：设计与原型入口

本文集保存个人 fork 的协作助手目标、责任边界和原型状态，供用户和冷启动 agent 接续。2026-11-05 用户已接受首个原型增量及模拟验收边界；实现和使用限制由 prototype.md 维护。上游产品说明仍在父目录的编号文档中。

## 当前目标与阅读路径

助手形态为单项目、一个主要对话的独立协作 agent，在 Harness 的 loop 中围绕当前目标自主获取依据、思考和使用工具。目标是帮助用户理解工程问题、探索想法，形成有效结论、决定或可承接工作。[design-focus.md](design-focus.md#已确认的助手形态与实现分界) 维护目标与分界；后续 agent 应先读该节，再使用任务板。场景用于检查能力是否足够，不直接转换成开发流程。

助手在系统中的位置及应知道的运行背景见 [助手的位置、运行背景与应有认知](design-focus.md#助手的位置运行背景与应有认知)：稳定身份和分责应传达，环境与后台当前状态据实取得，框架实现细节按需读取。该要求不等于运行提示词已完整包含这些内容。

## 整体盘点

| 方面 | 当前结论与边界 |
| --- | --- |
| 已确定 | 目标、六项能力及职责；agent 自主组织工作；按需活跃、允许相关事件唤起；不承担全程执行或全面项目管理 |
| 已确定实现分界 | 系统提供工具、信息、说明、边界及具体操作/运行合同；agent 自主理解、查据、澄清、沉淀和答复。六项能力不对应六套必建流程 |
| 已确定 | 项目资产与助手记忆分工；默认主动沉淀与 agent-docs 意识；原始对话查询和工作来源线索作为恢复兜底 |
| 已确定 | 助手记忆的查询/新增/修正/停用/删除、按需获取和适用性判断、使用中修正；回顾提炼为可选扩展 |
| 已确定形态 | 单项目、一个主要助手对话＋并行工作状态可见性；原型复用现有面板，多对话移出范围 |
| 已确定分责 | 协作助手与原主 Session 的后台调度职责分开；调度会话默认隐藏，高级设置可显示，不改变后台运行 |
| 已确定身份 | 助手先服务本项目 DSH 界面用户；外部来源继续走原主 Session 链路，可按用户要求读取和定向操作，不自动接管外部需求讨论 |
| 已确定操作边界 | 对话正常交互，影响操作通过工具/接口；不把整段助手交流订阅给工单。feature 仅为使用语义，不新增插件实体或生命周期 |
| 已确定交接方向（高重要性） | 建单与派工分别据实表达；配套反馈关联并保留原始来源。原型机制见 prototype.md，目标要求见 design-focus.md |
| 沿用工程基础 | DSH 会话/模型/工具/工作区，以及 superagent 的来源、工单、执行和反馈机制；事实证据见 current-system.md |
| 用户提供的基础 | docs-workflow 协调文档维护，RouteLedger 承接适用的阶段与推进记录；按能够接入使用评估，尚未在本仓库完成接入 |
| 首个实施增量 | 独立助手角色、真实工单交接和反馈、原始历史查询、讨论接续记录与现有面板入口；个人偏好记忆不在本增量 |
| 后续选择 | 个人偏好记忆、可选回顾 skill、真实模型体验改进；没有选定向量库。客户端与 GitHub 真实联调尚未验证 |

本轮没有确认还需新增一套资产治理、项目管理或执行调度系统。已有基础的可复用范围与适用限制在其对应文档维护。

## 来源、证据与维护

需求讨论来源为 Codex 对话（2026-11-02 至 2026-11-03）；原型范围与环境限制于 2026-11-05 接续确认。本目录是提炼资产，不是逐字记录；原始完整对话未导出到仓库。

- `foundations.md` 记录用户明确接受或明确纠正后的结论；相关用户原意在文内注明。
- `current-system.md` 记录本次静态检查支持的行为，附仓库源码引用，不代表运行验证。
- `design-focus.md` 维护已确认的助手形态、目标、自主行为与系统支撑分界；具体待选机制不因此成为已接受规格。
- `assistant-memory.md` 维护助手记忆要求及可选扩展，与项目资产规则分开维护。
- `interaction-proposals.md` 保留助手提出但用户尚未逐项接受的设计，不能直接作为实施授权。
- `prototype.md` 维护首个实际实施增量、工具契约、使用方式及验证限制。
- `task-board.md` 按实现分界维护已交付支撑、能力缺口、待核查项及可选方法；`next-batch-plan.md` 保留已撤下推荐的原第二批提议，不能作为当前计划。

本轮正在以项目资产方式保存讨论，尚无独立的跨会话助理记忆。更换会话时，可从此入口接续。

后续在对应文件中改写有效结论和待决问题，保持一项内容一个维护归属；不在入口追加一套重复的需求或会话流水账。文档中记录的授权背景不替代实际操作授权。
